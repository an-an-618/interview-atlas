# Interview Atlas（千面）

Interview Atlas 是一个本地优先的面试知识整理工具，中文产品名为“千面”。

产品希望帮助求职者把分散、非结构化的面试经验整理成可以编辑、复用、关联和复习的个人知识库。用户可以导入面经，将内容拆解为原子化的问答块，并通过同步块管理不同面试记录中反复出现的问题。

## 当前阶段

项目处于产品需求探索阶段。仓库目前只包含工程治理和需求评审材料，尚未选择应用框架、数据库、编辑器、AI 服务商或桌面运行方案，也不包含业务代码。

## 产品设想

- 导入面试经验，并通过 AI 辅助提取问题、答案和相关材料
- 对原子化问答块进行自由编辑、复用和组合
- 用同步块整理高频问题及相对稳定的回答思路
- 在首页集中复习个人高频问题
- 解析简历，并把问题关联到具体实习或项目经历
- 按用户自己的方式建立分类、文件夹和索引
- 二期支持录屏、视频关联与转写

## 开发原则

- 本地优先，用户控制自己的数据
- AI 功能采用用户自备 API Key 的方式
- AI 提取、匹配和同步结果必须允许人工确认与纠正
- 通过 Git 和 GitHub 保持每次变更可追踪、可回滚
- 先完成需求评审和技术决策，再创建应用脚手架
- 禁止把 API Key、简历、面试录屏和用户隐私数据提交到 Git
