# Architecture Decision Records

Architecture Decision Records preserve important technical choices and their reasoning.

## Workflow

1. Copy `0000-template.md`.
2. Use the next four-digit sequence and a short English title.
3. Start with `Proposed`.
4. Merge only after the decision has been reviewed.
5. Mark accepted decisions as `Accepted`.
6. Replace an obsolete decision with a new ADR and mark the old one `Superseded`.
