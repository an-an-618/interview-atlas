见字·如面 **2.1 · 独立模块与统一信笺界面** 同步此前全部本地开发更新。

- 首页、面试记录、原子问答、聚合块、简历经历、模拟面试恢复独立入口；原有导入、AI 提取、人工审核、编辑、关联、来源跳转、历史报告和备份继续使用。
- 全站共用暖纸／深绿控件、统一图标和焦点规范，以留白减少重复边框；保留闪卡翻面、滑动、触控板、键盘和洗牌动画。
- 手机共用响应式网页，触摸控件至少 44px；浏览器检查覆盖 320–1904px 的 10 种宽度、真实触摸和 75%–200% 实际浏览器缩放。
- 新建保存失败保留内容；旧标签页迁移到对应模块，不清空既有数据。沿用 v11 备份及原应用标识。
- 跨电脑开发说明、依赖锁文件、界面与产品规则全部进入仓库；安装 Node.js 24 后执行 `npm ci`、`npm run dev` 即可继续网页开发。桌面构建还需 Rust 1.90 和平台工具。

下载与体验：

- **Mac**：Apple Silicon、macOS 15+ 使用 `Interview-Atlas_2.1.0_aarch64.dmg`。
- **Windows**：Windows 10/11 x64 优先使用 `.exe` 安装器；MSI 用于管理部署。缺少 WebView2 时安装器会联网安装运行时。
- **Web／手机**：`Interview-Atlas_2.1.0_web.zip` 是生产静态文件，解压后通过 HTTP(S) 静态服务器提供访问；不要双击 `index.html`。开发时用 `npm run dev -- --host 0.0.0.0`，手机与电脑在同一网络下访问终端中的 Network 地址。录音等能力依赖浏览器与安全上下文；双路系统录音目前仅在 macOS 桌面端可用。
- 每种下载附带 `SHA256SUMS-*.txt`。安装包来自此标签的 GitHub Actions 原生构建，发布前核验校验值。

升级前请在设置页导出 JSON 备份。个人数据仍保存在当前客户端本地；换电脑或客户端时显式导入备份，API 密钥需重新配置。

macOS 安装包尚未 Apple 公证，Windows 安装包尚未 Authenticode 签名，首次安装可能需要系统确认。安装说明见 [中文 README](https://github.com/an-an-618/interview-atlas/blob/v2.1.0/README.zh-CN.md)；开发接续见 [开发交接说明](https://github.com/an-an-618/interview-atlas/blob/v2.1.0/docs/engineering/development-handoff.md)。
