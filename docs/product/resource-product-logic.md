# 见字·如面：恢复已有产品逻辑

2026-11-11 用户确认：恢复大改版前的产品逻辑，把原有原子能力套在当前 UI 上；避免新造词和新的抽象工作流。本文件优先于 2.1 重构中通用知识库与连续整理的页面方案。2026-11-26 随 2.1 发布同步到 GitHub。

| 入口 | 已有能力与操作 |
| --- | --- |
| 首页 | 当前信笺布局、共享闪卡、导入面经、模拟面试、待审核与最近更新；内容点击后进入各自模块 |
| 面试记录 | 搜索、筛选、原有面经集合；面试详情保留基础信息、可展开原文、问题目录、当次回答、笔记、来源与聚合块入口 |
| 导入 / 录制 | 原有文本导入或双端录音转写；原文先保存，AI 提取后人工采纳 / 忽略；可后台处理、稍后审核与重试 |
| 原子问答 | 独立创建；来源 / 时间 / 文本筛选；详情编辑问题、回答、笔记；查看来源面试和具体关联对象 |
| 聚合块 | 创建、搜索、收藏、目录收起；原有正文和复习笔记就地编辑；按需展开关联问答；在具体问答入口选择已有或新建聚合块 |
| 简历经历 | 解析简历、人工新增、展开、编辑、删除；原有经历与问答 / 聚合块关联 |
| 模拟面试 | 原有面试间、配置、会话续办、历史记录和报告；保留当前 harness 与真实回答证据校验 |
| 设置 / 搜索 / 分享 | 原有模型设置、录音设置、示例、备份导入导出、全局搜索、分页分享图 |

不再挂载 `KnowledgeWorkspace`、通用比较和关联弹窗，也不挂载 `OrganizeWorkspace`、`ReviewWorkspace`。模拟面试报告恢复原有总体观察、有效表现、改进项、逐题反馈和面试记录入口，保留已核验的回答引用。旧域模型与已保存的本地数据仍兼容；不清空、不重导入，也不将旧标签页恢复到失效入口。曾经停留在知识库的标签页按选中对象进入对应模块，整理标签页进入面试记录，模拟练习标签页进入模拟面试。旧的未提交工作台草稿保留在本地。

视觉沿用全站暖纸、深绿、浅绿选中、统一按钮 / 图标、单下划线搜索与低边界密度。面试详情保留问题目录与正文两列，原文按需展开；聚合块目录与正文以留白分隔；窄屏自动单栏，一级导航三列两行。闪卡比例、翻面、滑动、键盘、洗牌动画和 132×44px 中性色洗牌热区保持原样。
