# 聚合块查找与阅读优化

日期：2026-10-30。范围来自本地项目检视后的优化请求，使用 `feature/aggregate-block-polish` 分支交付。

## 验收标准

- 界面统一使用“聚合块”，保留 `SyncBlock`、`syncBlocks` 等内部字段和备份格式 v10。
- 搜索覆盖标题、回答、复习笔记。多个关键词可以分布在不同字段，且必须全部命中；英文大小写、全半角和连续空白不影响查找。
- 已隐藏的聚合块不进入目录、侧栏计数或收藏范围。
- 搜索或切换收藏范围时展开目录，避免结果被收起的目录遮住。清除搜索后恢复当前范围，并把焦点交还搜索框。
- 保留目录收起、正文编辑、复习笔记、关联问答和简历经历入口，在桌面和手机尺寸下均可操作。
- 将聚合块页面与公共页面框架拆成独立组件，保持其他页面行为。
- 产品文档采用 ADR 0003 已接受的会话凭据边界。系统安全存储仍需另行决策。

## 验证方法

运行 `npm test`、`npm run typecheck`、`npm run build` 和 `git diff --check`。

界面回归使用项目现有的外置 Playwright 方式，不增加运行依赖。启动单独的开发服务后执行：

```sh
APP_URL=http://127.0.0.1:43227 \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
SCREENSHOT_DIR=/absolute/path/to/screenshots \
node scripts/check-aggregate-blocks.mjs
```

脚本使用独立浏览器上下文与虚构工作区，验证目录折叠、搜索、收藏、空结果恢复、编辑持久化、旧备份字段及 1440/390/320 像素布局。禁止发起真实模型请求或读取用户工作区。
