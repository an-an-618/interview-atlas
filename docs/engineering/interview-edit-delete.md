# 面试记录编辑与删除

任务：GitHub Issue #16。

验收标准：

- 粘贴转写内容不把“发言人”或对话当公司名；无法识别时保留未命名状态，导入时可填写公司、岗位、轮次、日期。
- 面试列表以公司为标题、岗位与轮次为副标题，来源单独保留在详情。
- 面试详情可编辑基础信息及原子问答的问题、答案、笔记、标签；原子问答模块共享同一条记录。
- 列表删除需二次确认，展示所属问答数量及不可恢复说明。
- 删除面试、所属问答、该面试 AI 审核数据，并清理所有指向这些实体的关系；同步块、简历经历、其他面试和复习事件保留。
- 若历史数据存在多个面试共用同一原子问答，按所属问答一并删除，同时清理其他面试中的引用。
- 删除通过 IndexedDB 的跨存储事务完成，失败时保留界面记录并显示错误。
- 验证元数据识别、编辑后的关系保留、删除边界及 PC/H5 操作。

验证命令：

```sh
npm test
npm run build
APP_URL=http://127.0.0.1:43230 PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node scripts/check-interview-lifecycle.mjs
```

浏览器脚本使用独立上下文及虚构数据，覆盖导入信息核对、PC/H5 编辑、跨模块同步、刷新持久化、取消删除、写入失败后重试和关联清理。也可通过 `CHROME_CDP` 连接自动化 Chrome。macOS 启动参数包含 `--use-mock-keychain --password-store=basic`，脚本结束关闭自动化浏览器。

本轮浏览器所有断言已通过；执行环境另报告 Chrome 的 Crashpad/系统偏好写入被沙箱限制，因此包装命令退出码为 1。未使用或修改个人浏览器数据。
