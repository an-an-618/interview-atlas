# 首页闪卡

首页采用信笺工作台布局：桌面左侧为欢迎文案、瘦高闪卡轮盘与最近整理，右侧为墨绿色模拟面试入口和收藏。根据实际内容区宽度切换单双栏，手机保留顶部导航和底部操作栏，内容正常纵向滚动。

- 设置中的「首页闪卡」开关默认开启，使用本机 `localStorage` 的 `interview-atlas-home-flashcards` 保存显示偏好。关闭后最近整理紧接欢迎文案，收藏与模拟面试入口仍可使用；存在候选或拆解任务时保留待审核。再次开启不改变当前会话的抽卡顺序与位置。
- 默认抽取未隐藏的聚合块，也可切换为原子问答。没有内容时提供创建入口，或使用另一个已有内容的来源。
- 正面只展示问题，背面展示回答。卡片下部的「翻转查看答案」与「回到问题」采用无边框的图标加文字入口，控制 3D 翻面，正反面尺寸一致。换卡后先展示问题面，不再提供折叠回答。
- 复习栏右上提供「洗牌」。点击时先生成待提交的新顺序，直接让七张真实卡片沿当前灰色曲轴的实际椭圆轨迹环绕；后半段平滑减速，逐渐对齐各自正式位置、缩放与亮度，约 2.2 秒停住并保持 0.3 秒，总计约 2.5 秒。Web Animations 关键帧采用速度曲线的积分确定转角，终点使用当前响应式布局的实际变换。动画结束仅提交已确定的顺序、移除动画，同一张中心卡的 DOM 节点、内容、编号、位置和尺寸保持连续，不使用替身卡片或再次抽取结果。洗牌期间锁住来源、翻面与换卡，完成后从新顺序的第一张开始，不改变内容或收藏。只有一张时禁用洗牌；减少动态效果时直接展示结果；离开主页会取消动画和未提交的洗牌。
- 问题在卡面中部使用衬线字体。较长问题采用更适合多行的字号和行距；超长问题与回答可以在卡内纵向滚动，保留完整内容与固定的翻面入口。
- 左侧按钮、左方向键切上一张；右侧按钮、右方向键切下一张。手指或鼠标向左拖动看下一张、向右拖动回上一张；触控板横向滚动同样支持双向切换。卡片区域聚焦后，空格翻面。
- 当前卡片居中、放大、高亮，前后卡片缩小、倾斜、变暗；灰色半圆弧线静止时仅保留 12% 不透明度，洗牌时平滑增强，结束后淡回背景。轴线的几何尺寸保持不变，继续作为真实卡片的洗牌轨迹。换卡时各张卡片沿轮盘移位，逐渐改变大小与亮度。使用虚拟序号保留即将进入中心的真实卡片节点，首尾循环以及两张卡片的情况均不重新挂载进入中心的卡片。
- 每次启动应用，以 Fisher–Yates 洗牌。聚合块与原子问答各自保留本次启动的顺序和当前位置，支持首尾循环及回看。收藏、编辑、切换页面不重新洗牌；新增项加入顺序，删除或隐藏项退出，尽量保留当前卡片，被删除时继续到下一个有效项。
- 收藏仅由右上角星标控制，不切换卡片。聚合块复用原有 `favorite`；原子问答的可选 `favorite` 同样保存到本地工作区及 JSON 备份。旧数据保持兼容。
- 点击问题、回答或「查看详情」进入当前内容详情。关联问答数量保留在卡片底部，点击打开当前聚合块详情，首页不展开关联内容。
- 桌面左右按钮在悬停卡片区域或键盘聚焦时出现，触摸设备保留可见入口。非当前卡片及当前隐藏的一面均设置 `inert` 与 `aria-hidden`，不接受交互或进入辅助技术阅读顺序。翻面时保持按钮焦点，换卡时把离开卡片的焦点移回轮盘区域。
- 非被动 wheel 监听阻止原生横向滚动，连续惯性只换一张；横向事件停顿超过 220ms 后允许开始下一次手势。纵向滚动与 Ctrl + wheel 缩放保持原生行为。短拖动回弹，纵向触摸不换卡。支持减少动态效果。
- 首页嵌入模式的桌面卡片最大 260 × 390px，窄栏最大宽度 220px，保持 2:3 比例。按内容区宽度缩放，避免短窗口压扁卡片。复习容器使用 `overflow: clip`，避免浏览器把翻面后的控件滚入视野时滚动轮盘；问题与答案分别保留自身滚动区域。
- 最近整理按更新时间混排面试记录、未隐藏聚合块和原子问答，展示最近五项；顶部搜索将输入传入全局搜索，「查看全部」打开未筛选的知识资产。收藏同时包含聚合块和原子问答，所有入口沿用原来的详情导航和本地数据。
- 从主页进入模拟面试间时，在显示入口或设置页之前重置页面滚动到顶部；已开始的面试对话保留原来的消息跟随滚动。

验证命令：

```bash
npm run build
npm test
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
APP_URL=http://127.0.0.1:43118 \
node scripts/check-review-cards.mjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
APP_URL=http://127.0.0.1:43118 \
node scripts/check-home-workbench.mjs
```

浏览器检查使用隔离上下文及示例数据，不改动当前浏览器中的真实工作区。检查包含正反面、双向循环、收藏持久化、来源与页面切换、真实触摸与鼠标拖动、键盘、触控板惯性、动效中真实节点晋升、长问题及桌面和手机尺寸。可用 `--settings-only` 或 `--shuffle-only` 单独检查主页显示设置，或洗牌时序、减速、停住时与结果的节点/内容一致、位置及尺寸差异小于 0.5px，以及面试间吸顶。

工作台检查覆盖 14 组窗口尺寸（320–2560px，含横屏）、收起/展开侧栏、搜索传参、混合最近整理、两类收藏、审核入口及空工作区。另用临时 Chrome 配置实际设置 75%、100%、125%、150%、200% 页面缩放，并通过 CSS 视口宽度与 `devicePixelRatio` 确认缩放生效，再检查布局、洗牌和翻面。
