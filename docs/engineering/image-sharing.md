# 图片分享

## 范围与验收

- 原子问答详情、面试详情中的问答、聚合块详情、单条简历经历和整场面试详情均有「分享」入口。
- 所有图片统一为 1080 × 1440 PNG（3:4 竖图），配色、字体和留白沿用现有产品。问题与回答、经历要点完整导出。
- 制图采用暖色信笺纸、细边框、淡横线和植物线描。原子问答页眉不显示「知识札记」「原子问答」或英文产品名；单页图片不显示页码，多页图片保留页码。
- 整场面试分享入口位于详情标题区域右上角，窄屏同样保持该位置。
- 聚合块仅包含其标题与聚合回答，不包含关联原子问答的标题或回答。
- 来源面试、时间、标签、笔记按有无内容提供开关，默认关闭。来源与时间分开控制。
- 产品水印开关始终可用，默认关闭。开启后在每页页脚分两行显示 `「见字·如面」提供制图支持` 与 `产品地址：https://github.com/an-an-618/interview-atlas`，关闭后图片不含产品名或仓库地址。
- 来源面试逐条编号，续行保持悬挂缩进，条目间留出间距。短来源列表整体换页，普通条目尽量不跨页；过长列表分页后重复「来源面试 · 续」标题，完整保留来源文字。
- 整场面试导出全部已整理问答，可附原始记录；未整理问答时默认导出原始记录。简历分享需先应用未保存的修改。
- 长内容按文字测量自动分页，预览提示页数，支持翻页、当前页下载、全部下载。多页文件带页码。
- 图片生成不需要 AI、凭据、网络或外部图片服务，不修改本地内容及关系。浏览器使用 Blob 下载，桌面端写入系统下载文件夹，重名通过后缀保留既有图片。

## 实现

`src/domain/share.ts` 构建只读分享快照、可选信息及文件名；关系解析兼容单侧旧引用。`shareLayout.ts` 按 grapheme 测量换行并按行分页，保持原文和顺序，标题同样可分页；来源列表单独测量缩进宽度，并优先保留列表和单条来源在同页。使用本地字体与 Canvas 2D 生成预览和 PNG，无新增依赖或持久化字段。纸张纹理与装饰通过确定性绘图生成，水印不参与正文分页。

`src/components/Share.tsx` 提供可访问的模态预览、信息开关、页数提醒与下载状态。只渲染当前预览页，减少长面试占用；批量导出顺序生成图片。浏览器可能要求允许多文件下载，界面在发起下载后说明并提供逐页下载回退。

`src-tauri/src/share.rs` 提供范围受限的 `save_share_image`，只接受 PNG 文件名及 1080 × 1440 PNG 数据，使用操作系统下载目录，拒绝路径与覆盖。无需新增文件系统插件权限。
